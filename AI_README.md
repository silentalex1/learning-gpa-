# Portable AI Project - WEB

This project includes an embedded AI model that works without Forge installation.

## Model Information
- **Model**: qwen2.5-coder:14b
- **Location**: models/embedded/qwen2.5-coder-14b/
- **Size**: 8.37 GB
- **Project Type**: web
- **Mode**: Portable (works offline)

## Quick Start

### For WEB Projects:

Open `browser_ai.html` in your browser - no backend needed!

## Requirements

### For Native Mode (Recommended)
- Python 3.8+
- llama-cpp-python: `pip install llama-cpp-python`

### For Ollama Mode (Fallback)
- Ollama installed and running: `ollama serve`

## Distribution

To share this project:
1. Zip the entire project directory
2. Send to others
3. They just need Python + llama-cpp-python (or Ollama)
4. No Forge installation required!
